Gym Badge PDP Nano Banana Pro Prompt Brief

Use this as the copy-paste source for the new gym badge product page assets. The strategy is simple: make the collector pack feel like the obvious completion move, prove the finish in one glance, and keep the page visual enough to wake a cold paid-click visitor up fast.

Prompting Rules From Google's Guides

Google's Nano Banana Pro guidance emphasizes detailed prompts with subject, composition, action, setting, style, direct edit instructions, camera/lighting, exact text in quotes, aspect ratio, production resolution, and clear roles for reference images.

Sources: Nano Banana Pro prompt tips and Gemini Image prompt guide.

  • Upload the listed reference images first, then paste the prompt.
  • Generate desktop and mobile versions separately. The mobile version should be recomposed, not cropped.
  • For in-image copy, keep words huge, exact, and minimal. If the text is wrong, regenerate or ask Gemini to correct only the text.
  • Do not add anime characters, monster characters, franchise logos, or brand names. The pins carry the nostalgia; the page should feel premium and collectible.

Optional Retouch Prompts

Use these after a generation is close but needs cleanup.

  • Correct only the rendered text. It must say exactly "[TEXT]" with no extra words. Preserve everything else.
  • Make the badges match the uploaded product reference more closely. Preserve the scene, lighting, and composition.
  • Recompose this for mobile 4:5. Do not crop off any badge or text. Keep the product large and central.
  • Remove any character, logo, franchise name, or extra prop. Keep only the product, packaging, and clean lifestyle context.
